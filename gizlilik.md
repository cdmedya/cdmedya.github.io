# CD Medya Yukleme gizlilik politikası

Son güncelleme 22 Ekim 2026.

Bu politika, CD Medya'nın kendi YouTube kanallarını yönetmek için kullandığı CD Medya Yukleme programını anlatır. Programı yalnız kanal sahibi kendi bilgisayarında kullanır.

## Program hangi verilere erişir

Program, kanal sahibinin Google hesabıyla verdiği izinle YouTube Data API ve YouTube Analytics API hizmetlerini kullanır. İzin yalnız onay ekranında seçilen kanal için geçerlidir. Program bu kanalın şu bilgilerine erişir:

- Kanalın adı, kimliği ve ayarları okunur.
- Kanala yüklenen videolar, başlıkları, açıklamaları, kapakları, alt yazıları ve yayın zamanları okunur ve düzenlenir.
- Videolara yazılan yorumlar okunur ve kanal sahibinin onayıyla cevaplanır.
- İzlenme, izlenme süresi ve izleyici kitlesi istatistikleri okunur.

Program başka bir Google hizmetine, e-postaya, kişilere ya da izleyicilerin hesaplarına erişmez.

## Veriler ne için kullanılır

Veriler yalnız kanalı yönetmek için kullanılır. Videolar yüklenir ve yayın saatine zamanlanır, istatistiklerden haftalık rapor hazırlanır ve yorumlara cevap taslağı yazılır. Veriler reklam için kullanılmaz, satılmaz ve üçüncü kişilerle paylaşılmaz.

## Veriler nasıl saklanır

Google'ın verdiği izin anahtarı yalnız programın çalıştığı bilgisayarda tutulur ve Windows'un veri koruma hizmetiyle şifrelenir. İstatistik raporları da aynı bilgisayarda saklanır. Program verileri herhangi bir sunucuya göndermez.

CD Medya Yukleme'nin Google API'lerinden aldığı bilgileri kullanması ve başka bir uygulamaya aktarması, sınırlı kullanım şartları dahil [Google API Hizmetleri Kullanıcı Verisi Politikası](https://developers.google.com/terms/api-services-user-data-policy)'na uygundur.

## İzin nasıl geri alınır

Kanal sahibi verdiği izni istediği zaman [Google hesabının üçüncü taraf erişimi sayfasından](https://myaccount.google.com/connections) geri alabilir. İzin geri alınınca program o kanala erişemez.

## YouTube ve Google şartları

Program YouTube API Hizmetlerini kullanır. YouTube hizmetlerinin kullanımı [YouTube Hizmet Şartları](https://www.youtube.com/t/terms)'na, verilerin Google tarafından işlenmesi [Google Gizlilik Politikası](https://policies.google.com/privacy)'na bağlıdır.

## İletişim

Bu politika hakkındaki sorular için cdmedyateknolojileri@gmail.com adresine yazabilirsiniz. Politika değişirse bu sayfa güncellenir ve tarih yenilenir.

## English

**Privacy policy of CD Medya Yukleme (last updated 22 October 2026).** CD Medya Yukleme is a desktop tool that CD Medya uses only to manage its own YouTube channels. It runs only on the channel owner's computer.

With the permission granted on Google's consent screen, the tool uses the YouTube Data API and the YouTube Analytics API for the selected channel only. It reads channel details, reads and edits the channel's videos, titles, descriptions, thumbnails, captions and publish times, reads comments and replies to them with the owner's approval, and reads view and audience statistics. It does not access any other Google service or any viewer's account.

The data is used only to manage the channel. It is not used for advertising, not sold and not shared with third parties. The authorization token is stored only on the computer that runs the tool and is encrypted with the Windows Data Protection API. No data is sent to any server.

CD Medya Yukleme's use and transfer of information received from Google APIs adheres to the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements.

The owner can revoke access at any time on the [Google Account third-party access page](https://myaccount.google.com/connections). The tool uses YouTube API Services. See the [YouTube Terms of Service](https://www.youtube.com/t/terms) and the [Google Privacy Policy](https://policies.google.com/privacy). Contact: cdmedyateknolojileri@gmail.com
